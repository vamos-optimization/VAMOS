# VAMOS 1.0 compatibility baseline

These files are the permanent machine-readable baseline for the stable VAMOS
1.0 Python API, CLI, exit codes, algorithm configuration, and artifact schemas.
`artifact_fixtures.json` contains lossless canonical files produced by a clean,
noneditable VAMOS 1.0.0 wheel installation: a completed study, a study completed
with failures, their successful and failed RunManifests, and both study-inspection
JSON command results. The small result arrays are stored as base64-encoded NPZ
bytes; JSON files retain their exact UTF-8 bytes. Every member has a size and
SHA-256 digest. This transport envelope is test data, not a runtime artifact schema.

The artifact tests materialize these fixed bytes under a temporary root and
exercise public loading, verification, inspection, summary, and CLI operations
without rerunning optimization or changing the stored files. Creation timestamps,
IDs, and producer environment remain the original evidence; they are not
rewritten to resemble the machine running a future compatibility check.

**Development after 1.1.0:** the structural snapshots freeze more than names.
`stable_public_api.json` records the signature (parameter names, kinds, and
defaults; not annotations) of every stable callable and of the public methods of
the stable classes. `stable_algorithm_configs.json` records the field defaults of
the configuration classes and the output of `Config.default()`. The generator
reads the stable CLI arguments from the argparse parsers rather than from the
help text, and the exit codes from the code that maps outcomes to codes.
The check accepts built-in algorithm identifiers added after the frozen ones
in `stable_algorithm_configs.json` (such as `ccmo` and `ctaea`), but not the loss of one,
and it does not record the configuration classes of algorithms added after 1.0.

Regenerate the structural snapshots only through:

```bash
python tools/generate_v1_compatibility_snapshots.py
```

Capture artifact fixtures only from an isolated 1.0.0 wheel environment outside
any source checkout, with the supported compute dependencies installed and
`PYTHONPATH` unset:

```bash
python /path/to/VAMOS/tools/generate_v1_artifact_fixtures.py --output /new/artifact_fixtures.json
```

The capture tool refuses an existing destination. Review newly generated bytes
before installing them here; ordinary validation reads the committed fixtures
and never regenerates them. The producer is identified by its installed package
content hash, so no fixture claims the Git revision of a surrounding checkout.

Changing an existing snapshot requires explicit compatibility review. Future
1.x releases must continue to pass the corresponding checks and load and
inspect the committed 1.0.0 artifact fixtures. Pre-1.0 artifacts do not belong
in this directory.
