# PPS configuration

Configure `pps` through `vamos.algorithms.PPSConfig`. This page is the parameter reference, not a tutorial about the algorithm; see [PPS](../../../algorithms/pps.md) for the algorithm, its push and pull stages and its budget rule.

**Development after 1.5.2.** The [1.0 compatibility baseline](../../../project/stability-and-versioning.md) does not cover PPS and `PPSConfig`.

```python
from vamos.algorithms import PPSConfig
```
