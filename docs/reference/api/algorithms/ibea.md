# IBEA configuration

Configure `ibea` through `vamos.algorithms.IBEAConfig`. This page is the parameter reference, not a tutorial about the algorithm.

**Stable public API.** The [1.x compatibility policy](../../../project/stability-and-versioning.md) defines the supported surface; import from the public facade shown below.

```python
from vamos.algorithms import IBEAConfig
```
